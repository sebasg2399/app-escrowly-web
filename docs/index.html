Escrowly

Interactive diagrams documenting the architecture and core flows of the Escrowly monorepo (Fastify + React + Prisma + Stripe Connect). Each link opens a standalone viewer with theme switching, pan/zoom, search, focus, presentation, and PNG/JPEG/SVG export.

Diagrams

  • architecture Architecture overview

    Browser → React + Vite SPA → Fastify backend → Postgres / Stripe Connect. Outbound PaymentIntents & Transfers, inbound signed webhooks.

  • lifecycle Milestone lifecycle

    Escrow state machine: pending → funded → in_review → approved → paid, plus the recoverable Stripe Transfer failure path and the contract completion transition.

  • sequence Happy path — money flow

    Full roundtrip: client funds via PaymentIntent → webhook flips pending → funded → seller submits → client approves → Stripe Transfer pays the seller.

  • sequence Stripe Connect onboarding

    Backend mints an AccountLink → seller completes KYC on the Stripe-hosted page → status reconciled back into our DB.

  • sequence Auth flow

    Register / login → JWT access token in memory + opaque httpOnly refresh cookie → silent refresh with rotation → server-side logout revocation.
